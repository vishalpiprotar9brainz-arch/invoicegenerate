# Invoice Generator

A complete, production-ready, fully responsive Invoice Generator built with React and Tailwind CSS. Create professional invoices online, live preview them with multiple stunning templates, and export high-resolution PDFs directly from your browser. 

This project requires no registration, processes data 100% locally for absolute privacy, and works flawlessly across desktops, tablets, and mobile devices.

## Features

- **Live Real-time Preview:** See your invoice update precisely as you type.
- **10 Professional Templates:** Includes Modern, Corporate, Minimal, Agency, Executive, Startup, and more.
- **Flawless PDF Export:** Generates perfectly formatted A4 PDFs that match the preview exactly, with pixel-perfect resolution.
- **Fully Responsive:** Beautifully crafted layouts that scale and adapt dynamically to mobile, tablet, and desktop screens without breaking.
- **No Registration Required:** 100% free and instantly usable without accounts or paywalls.
- **Secure & Local:** All data is processed entirely in your browser—nothing is saved on our servers.
- **Custom Branding:** Upload your company logo and digital signature (or use our built-in elegant text fallbacks).
- **SEO Optimized:** Complete metadata, structured schema, and rapid load times.

## Installation Guide

Follow these steps to set up the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/vishalpiprotar9brainz-arch/invoicegenerate.git
   ```
2. Navigate into the project directory:
   ```bash
   cd invoicegenerate
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```

## Run Commands

To start the development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

The application will be available at `http://localhost:5173/` (or the port specified in your terminal).

## Build Commands

To create an optimized production build:

```bash
npm run build
```

This will bundle the application and output the static files into the `dist` directory, ready to be deployed to any static hosting provider (Vercel, Netlify, GitHub Pages, etc.).

To preview the production build locally:

```bash
npm run preview
```
